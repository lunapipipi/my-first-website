GitHub PagesでWebサイトを公開する方法

GitHub Pagesを使うと、HTMLとCSSで作ったWebサイトを無料で公開できます。 初心者でも、リポジトリを作ってファイルを追加すれば公開できます。

必要なファイル

基本的には、トップページとなるindex.htmlと、デザインを担当するstyle.cssがあれば始められます。

公開までの流れ

GitHubでリポジトリを作成し、index.htmlとstyle.cssを追加します。 その後、SettingsのPagesからmainブランチを選択すると公開できます。

まとめ

GitHub Pagesは、Web制作の練習やポートフォリオ作成にとても便利です。
